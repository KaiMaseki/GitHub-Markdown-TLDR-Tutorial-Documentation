## Headings

Headings are the basis of any kind of formatting. Without headings,

Everything \
Would look like \
a Mess \
Like This \

To add Headings you can use the hash sign (#) to make up to 6 Headings:

```
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6
```
Resulting in this:

# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6

Alternatively you can also use HTML's way of the heading command like so:

```
<h1> Heading 1 </h1>
<h2> Heading 2 </h2>
<h3> Heading 3 </h3>
<h4> Heading 4 </h4>
<h5> Heading 5 </h5>
<h6> Heading 6 </h6>
```
